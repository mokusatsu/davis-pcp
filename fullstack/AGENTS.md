# DAVIS-PCP データ操作ルール(共通)

本書はDAVIS-PCP Fullstackの全グラフビューが従う共通ルールである。新規ページ・可視化を追加する場合は必ずこれに準拠すること。

## 1. 中央selection state(単一正本)

- サンプル(row)の**色分けと選択はすべてのグラフに即時反映される**。個別ビューが独自に選択状態を持ってはならない。
- 正本はRedux store `selection` スライス(`src/app/store.ts`)。全ビューはこれをprojectionする。
- 選択操作は `selectionApplied`(Add / Replace / Subtract / Toggle)、解除は `selectionCleared`、Focus / Delete / Reset to Base Data も中央dispatchで行う。

## 2. すべてのグラフでサンプルを選択できる

- **散布図系(PCP、ペアプロット、ファセット、PCA等)**: PCPと同じ選択機能(矩形ブラシ+ヒット判定、点クリックtoggle)を備える。
- **ヒストグラム・集約系**: 「当該グループの選択」として作用する。
  - (a) ビン選択: 棒/区間クリック → その値域に含まれるサンプル集合を選択
  - (b) グループ選択: L2色分けグループ(クラスタ/外れ値/木リーフ)の凡例・図要素クリック → そのグループ全体を選択
- 集合演算(Add/Replace/Subtract/Toggle)は「選択」プルダウンから共通UIで指定する。

## 3. マウスオーバー情報表示

- サンプルがプロットされている箇所では、**マウスオーバーで該当サンプルの情報(rowId、主要な値)を表示する**(tooltipまたはaria-live)。ホバー強調も中央store(`hoveredRowId`)経由で全ビュー同期する。

## 4. 二段階色分け(L1/L2)

色分けは次の2段階で構成し、描画設定でそれぞれ有効/無効を切り替えられる。

### L1色分け: 列の離散値(色相バリエーション)

- **numericを含め、欠損を除く観測値が1～20種類の列を色分け指定対象にする**。0種類・21種類以上は対象外。数値軸や尺度をカテゴリ型に変更しない。
- 種類数はデータセット全行から算出し、選択・Focus・サンプリングで色番号を変えない。未観測の定義値は数えず、missingCodesを除く。
- L1専用20色パレットの固定slot順を使う。色に加えてコード・値ラベルの凡例を表示する。
- 描画設定内で「列の値で色分け」セレクトにより列を変更できる。

### L2色分け: 解析結果グループ(輝度バリエーション)

- 対象は**クラスタリング結果・外れ値フラグ・決定木リーフ群**などの解析由来グループ。
- バリエーションは**輝度(luminance)**で行う(同一色相の明/中/暗ステップ)。
- L2はClusters/Models/Outliers等の解析ページでグループが作成されていることが前提のため、描画設定では**有効化のみ可能とし、解除(無効化)だけを提供する**(新規にここでL2グループを作ることはしない)。

### 同時適用

- L1とL2を同時に有効にした場合、**色相×輝度を合成**する: L1の色相を保持したまま、L2グループ違いを輝度差(明/暗)で表現する。両方の情報が一つの色から読み取れること。
- どちらか一方のみ有効な場合は、その段階単独の色分けになる。

## 5. グラフエリア共通要素(全グラフが備えるべきUI)

すべてのグラフビューのプロット領域は、次の共通要素を同じ意味で持つこと。

### 5.1 選択メニュー

- グラフ上部に**「選択」ボタン**(ドロップダウン)を配置する。
- 内容: ヒット判定(PCP等のブラシ系のみ)/集合演算(Add・Replace・Subtract・Toggle)/選択解除/Focus/Delete/Reset to Base Data。
- 実装例: `features/pcp/PcpPage.tsx` の `selectionMenu`。

### 5.2 矩形選択オーバーレイ

- ドラッグ中は**矩形をSVG最上位レイヤーに描画する**(セル背景より下に置くと白背景に隠れて見えなくなる。ペアプロットで発生した不具合)。
- 矩形は `fill="rgba(42,120,214,0.15)" stroke="#2a78d6" strokeWidth≥1.5` + `pointerEvents: 'none'`。
- ドラッグ確定後も矩形は即時消去してよい(選択結果が各ビューのハイライトで可視化されるため)。

### 5.3 選択ハイライト

- **選択されたサンプル/図要素は、そのグラフ内で明示的に強調表示する**こと。「中央storeには反映されているが見た目が変わらない」状態は未達成とみなす。
  - 点/線: サイズ拡大+不透明度上昇+選択色(`#2a78d6`)
  - 棒(ヒストグラム): 選択値域と一致するビンのみ強調
  - リーフ/グループ図形: 枠線強調+マーク(例: ✓)
- 強調は必ずそのグラフ自身の描画で行い、store参照だけで済ませない。

### 5.4 ヒット領域

- 小さな点でもクリックできるよう、マーク自体または透明のヒット領域を24px相当以上確保するか、nearest-point方式を使う。nearest-point方式の精度基準は**画面座標±8px以内**(PCP実装が基準例)。
- **ブラシ用pointerdownを持つSVGでは、選択可能マーク(circle/バー)上でのブラシ開始を抑止し、マーク自身のclickを優先する**(監査指摘1の再発防止)。実装は `onPointerDown` 冒頭の `target.closest('circle, rect[data-selectable]')` ガード。
- 集約系(ビン・グループ)選択も「選択」メニューの集合演算に従う(`getBrushOp()` を経由)。

### 5.5 テキスト誤爆防止(R10)

- プロット領域(svg/canvasコンテナ)には `user-select: none` を適用する(`src/theme/viz.css` 参照)。ドラッグ中に軸ラベルや凡例が選択反転してはならない。

## 6. 回帰チェックリスト(新規・変更グラフの受け入れ基準)

グラフを追加・変更したときは、次の表を埋めて回帰すること。1つでも×があれば未達成として扱う。

| # | チェック項目 | 確認方法 |
|---|---|---|
| R1 | 選択が他の全グラフへ反映される | グラフAで選択 → Table/PCP/sidebarで同数確認 |
| R2 | 他グラフでの選択がこのグラフでハイライトされる | Tableでcheckbox選択 → 当該グラフで視覚変化を確認 |
| R3 | このグラフ内でサンプルを選択できる(散布図系=矩形+点クリック、集約系=ビン/グループ)。**実ポインタ(page.mouse.down/up相当)で確認する** — JS合成イベントはブラシガードを素通りするため不十分 | 実操作で選択しsidebar数が変わることを確認 |
| R4 | 「選択」メニュー(集合演算/解除/Focus/Delete/Reset)がある(**ページ単位で配置可**。ページ内の全パネルの選択操作がそのメニューの集合演算に従うこと) | メニュー開いて確認+パネル選択が演算に従うか確認 |
| R5 | サンプルのマウスオーバーで情報が表示される | 点/棒にhoverしてtooltip確認 |
| R6 | L1色分け(colorBy列)が反映される。**numericを含む有効観測値1～20種類の列のみ** | 20種類を選択でき21種類は選べないこと、各画面の同一値が同じ色になることを確認 |
| R7 | L2有効時に輝度ステップで合成され、トグルが即座に再描画される(Clusters実行後) | L2トグルON/OFFでcanvasが即座に変わることを確認 |
| R8 | ドラッグ矩形がドラッグ中に視認できる(fill rgba(42,120,214,0.15)、stroke #2a78d6 幅1.5、最上位レイヤー、pointerEvents none) | ブラシ中のスクリーンショット |
| R9 | dataset切替後に破綻しない。**列数の大きいCSV・全NaN列を含むCSVでの切替も確認する** | 別dataset(大規模/欠損含む)を選んで再描画確認 |
| R10 | ドラッグでテキストが選択されない(user-select:none) | プロット領域でドラッグ → `getSelection()`が空+computed `user-select: none` |

## 実装対応(現状)

| 概念 | 実装位置 |
|---|---|
| 中央selection | `frontend/src/app/store.ts` (`selectionApplied`, `hoveredRowId`) |
| L1色相パレット | `frontend/src/theme/viz.ts` (`L1_COLORS`, `DARK_L1_COLORS`, `l1Color`) |
| L1候補・色番号 | `frontend/src/theme/useL1ColorDomain.ts` (`buildL1Domains`, `l1Index`) |
| L1/L2合成 | `frontend/src/theme/viz.ts` (`composedColor`: 色相×輝度ステップ) |
| L1列指定(共有store値) | `pcp.colorBy` — PCP描画設定で編集、Distribution/Statistics/pair plotが消費 |
| L2トグル | PCP描画設定「L2色分け」(`l2ColorEnabled`) |
| L2グループ | Redux `selection.groups`(クラスタ等)、GroupDefinition |
| 選択メニュー共通UI | `features/selection/SelectionMenu.tsx`(集合演算レジストリ `getBrushOp()` 経由で全パネルのグループ/ビン選択と連動) |
| user-select無効化 | `src/theme/viz.css` |
