# DAVIS-PCP データCSV仕様

## 基本形式

1行を1回答者・1観測、1列を1変数とする横持ちのCSVです。質問文や値ラベルなどの定義は、別ファイルの[コードブック](codebook-spec.md)で設定します。

| 項目 | 標準の扱い |
|---|---|
| 拡張子 | `.csv`。タブ区切りは `.tsv` |
| 文字コード | UTF-8推奨。UTF-8 BOM付きにも対応 |
| 区切り | CSVはカンマ、TSVはタブ |
| ヘッダー | 先頭行に列名。2行目以降がデータ |
| 引用符 | 二重引用符 `"` |
| 改行 | LFまたはCRLF |
| 列数 | 各データ行でヘッダーと同数。異なる場合は取込エラー |
| 空行 | 全セルが空白の行は読み飛ばす |
| 上限の既定値 | ファイル256 MiB、5,000,000行、500列。実行環境の設定で変更可能 |

文字コードはBOM、UTF-8、CP932、Shift_JIS、Latin-1の順で判定されます。日本語を確実に保持するにはUTF-8で保存してください。

カンマ・改行・二重引用符を含むセルは二重引用符で囲み、セル内の二重引用符は `""` とします。コメント行やタイトル行は置かず、先頭から表を記述してください。

```csv
respondent_id,gender,Q1,comment
R001,1,5,"使いやすく、満足しています"
R002,2,3,"説明に""例""があるとよい"
R003,1,98,
R004,2,99,
R005,1,,
```

## 列名と値

- 列名は重複のない名前にします。日本語も利用できますが、`Q1`、`age` などの短い名前と、コードブックの質問文を組み合わせると管理しやすくなります。
- ヘッダー前後の空白と引用符は除去されます。空の列名は `column` に、重複名は末尾に `_1` などを付けた名前に補正されます。コードブックの `name` は補正後の列名と一致させてください。
- データセルの前後の空白は、引用符で囲まれていても除去されます。
- 値は整数、浮動小数点数、文字列の順に判定されます。数値を引用符で囲んでも文字列型の指定にはなりません。
- `001`、`01` のような先頭ゼロ付きのコードは文字列として保持されます。`1` と `01` は別コードです。
- 列の尺度や役割はCSVの物理型だけでは確定しません。たとえば `gender` の値が1・2でも、コードブックでは `nominal` とします。
- 小数点は標準で `.`。桁区切りカンマは数値表記に含めないでください。
- `__rowId__` は内部の行ID列です。新規データの業務列名としては使用しないでください。

## 欠損値

標準の取込設定では、空文字、`NA`、`N/A`、`null`、`NULL`、`?`、`.` が欠損値になります。照合は大文字・小文字を区別しません。これらを文字どおりのカテゴリとして使う場合は、APIの `missingTokens` を変更する必要があります。

`NaN` は数値の非有限値として扱われ、設問別集計では無回答になります。空欄を使う方が明確です。

`98`、`99` などの独自コードは、標準の取込時には数値として保持されます。コードブックの `missingCodes` と `missingReasons` で非該当・無回答を定義してください。非該当と無回答を区別したいコードをCSV取込時の `missingTokens` に入れると、同じ空欄に変換されて区別が失われます。

## 読み込み手順

1. 画面上部の **Import** からデータCSVを読み込みます。
2. **コードブック**を開き、**CSV辞書読込**からCSVまたはJSONのコードブックを読み込みます。
3. 列名、尺度、役割、値ラベル、カテゴリ順序、欠損理由を確認します。

データCSVとコードブックは別々に読み込みます。CSVにコードブックの行を付け足さないでください。値ラベル付きで出力したデータCSVは表示用の値に置換されるため、元コードを保持した再分析用データには生値CSVを使います。

## APIの追加取込設定

`POST /api/v1/datasets/import` に `multipart/form-data` で `file` と、任意の文字列フィールド `options_json` を送ります。以下の詳細設定はAPIで指定できます。

| フィールド | 型 | 既定値・意味 |
|---|---|---|
| `encoding` | string | `utf-8`。この値のときは自動判定。`cp932` などを指定すると明示指定 |
| `delimiter` | string / null | null。形式に応じてカンマ／タブ。指定するなら1文字 |
| `quote` | string / null | null。標準は `"`。指定するなら1文字 |
| `hasHeader` | boolean | true。falseなら列名は `col_0`、`col_1`… |
| `decimalSeparator` | string | `.`。小数点文字 |
| `missingTokens` | string[] | `["", "NA", "N/A", "null", "NULL", "?", "."]`。指定すると置換 |
| `rowIdColumn` | string / null | null。明示指定する列は存在し、欠損がなく、一意であること |

行ID列を指定しない標準取込では、通常 `ROW-000001` などの内部IDが生成されます。`respondent_id` という列名だけで、その列が内部IDになるとは限りません。コードブックの `role: "id"` も取込時の行ID指定を変更する設定ではありません。

```json
{"encoding":"utf-8","hasHeader":true,"rowIdColumn":"respondent_id"}
```

実装の参照先: `fullstack/backend/app/services/import_service.py`、`services/dataset_service.py`、`api/datasets.py`、`storage/dataset_store.py`、`config.py`。
