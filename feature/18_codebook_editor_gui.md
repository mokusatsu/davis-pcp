## 1. 概要・目的

DAVIS-FEAT-017で定義されたコードブック（データ辞書）データモデルのフロントエンドエディタを実装する。

アンケートデータの実務分析では、変数名（`Q1`, `Q2_1`, `SQ1` 等）だけを持つCSVに対し、**数十〜数百問の質問文や選択肢ラベルを1問ずつ手入力するのは極めて非効率**である。調査票（Word/Excel/テキスト）から「行ごとに書かれた質問文リスト」や「選択肢テキスト」をコピー＆ペーストして一瞬で設定できる、実務直結の高速入力UIを提供する。

本仕様では、以下の3つの入力アプローチを統合した使い勝手の高いエディタを構築する：
1. **質問文（ラベル）一括貼り付け（Bulk Label Paste）**: 改行区切りテキストを流し込むだけで、変数順に一括マッピング。
2. **値ラベル・選択肢の一括ペースト & プリセット（Quick Value Labels）**: 「1:非常に不満\n2:やや不満...」や改行区切り選択肢を自動パースして即座に展開。5段階満足度などのプリセットも1クリック適用。
3. **ビュー切替（フォーム詳細ビュー ⇄ スプレッドシート・グリッドビュー）**: 1問ずつ細かく設定する2ペインビューと、Excelライクに全変数をテーブル表示してセル編集・範囲貼り付けできるグリッドビューを自在に往復。

## 2. 要件定義

### 2.1 質問文（ラベル）の一括貼り付け機能 (Bulk Label Paste)
1. **改行区切りテキストの流し込み**:
   - モーダル内の「📋 質問文一括貼付」ボタンをクリックすると専用ダイアログが開く。
   - Excelの1列やテキストファイルからコピーした質問文（1行＝1問）をテキストエリアに `Ctrl+V` で貼り付け可能。
2. **自動アライメント & プレビュー**:
   - 貼り付けられたテキストを行単位に分割し、現在の変数一覧（またはフィルタ・選択中の変数）と 1:1 で対応付けてプレビュー表示。
   - 「行番号」「変数名」「現在のラベル」「貼り付け後の新しいラベル」を並べて差分表示。
3. **柔軟な位置調整**:
   - **開始行オフセット**: 「Q3から貼り付けを開始する」「ID列や性別をスキップする」などの開始位置指定。
   - **空行・コメント行の扱い**: 空行をスキップするか、空ラベルとして割り当てるかのトグル。
   - **行数不一致の警告**: 変数数（例: 30変数）と貼り付け行数（例: 28行）が異なる場合、何行目まで適用されるかを明示表示。
4. **タブ区切り（TSV）対応**:
   - `変数名 \t 質問文` の形式で貼り付けられた場合、変数名の一致を自動検知して順序に依存せず正確にマッチング。

### 2.2 値ラベル・選択肢のスマート流し込み & プリセット (Quick Value Labels)
1. **テキストエリア一括パース**:
   - 値ラベル編集欄の「⚡ 一括貼り付け」ボタンから、複数行テキストを投入可能。
   - 以下の多様なフォーマットを自動判別してコード値とラベルを抽出：
     - **コード付きコロン/イコール区切り**: `1: とても不満`, `2 = やや不満`, `3. 普通`
     - **タブ区切り**: `1\tとても不満` (Excelから2列コピー)
     - **ラベルのみ（行ごとに1選択肢）**: `とても不満\nやや不満\n普通\nやや満足\nとても満足` → 1から昇順（1, 2, 3, 4, 5）に自動採番。
2. **調査定番プリセットのワンクリック適用**:
   - 満足度5段階（`1:大いに不満` 〜 `5:大いに満足`）
   - 同意度5段階（`1:全くそう思わない` 〜 `5:非常にそう思う`）
   - 賛否4段階（`1:反対` 〜 `4:賛成` / 中立なし）
   - 頻度5段階（`1:全くしない` 〜 `5:ほぼ毎日`）
   - 二値（`0:いいえ, 1:はい`、`1:男性, 2:女性`）
3. **選択中複数変数への一括適用**:
   - 左ペインで複数の変数（例: `Q1`〜`Q8`の評価問すべて）にチェックを入れた状態でプリセットまたは値ラベルを設定すると、選択した全変数に同一の選択肢定義を一括保存。

### 2.3 スプレッドシート・グリッド編集ビュー (Grid / Spreadsheet View)
1. **表示モード切替**:
   - エディタ右上に `[⊞ グリッド] [◫ 詳細フォーム]` の切替トグルを配置。
2. **テーブル直接編集**:
   - 全変数を一覧テーブル（列: `変数名`, `尺度`, `役割`, `質問文(ラベル)`, `値ラベル要約`, `欠損コード`, `逆転`, `MA`）で表示。
   - セルをダブルクリックして質問文や欠損コードをインライン直接編集。
   - 尺度・役割はセル内のセレクトボックスで即座に切り替え。
3. **範囲コピー＆ペースト (Ctrl+C / Ctrl+V)**:
   - グリッド上で複数行の「質問文」セルを選択し、Excelからコピーした内容を `Ctrl+V` で直接貼り付け可能。

### 2.4 標準フォームビュー（詳細編集）
1. **左右2ペイン構成**:
   - **左ペイン**: 変数一覧（尺度アイコン、検索ボックス、型フィルタ、一括チェックボックス）。
   - **右ペイン**: 選択変数の詳細（尺度・役割・逆転フラグ・欠損コード・値ラベルDnD並び替え）。
2. **カテゴリ順序の直感的編集**:
   - ドラッグ＆ドロップ（DnD）による順序入れ替え。
   - 「昇順」「降順」ボタンで即座にコード値順/ラベル順にソート。

### 5.2 主要ロジックの実装方針

#### (1) 質問文テキストパーサー (`parseBulkLabels`)
```typescript
interface ParsedLabelRow {
  lineIndex: number;
  rawText: string;
  variableName?: string; // TSV形式の1列目に変数名があった場合
  label: string;
}

export function parseBulkLabels(text: string, skipEmptyLines: boolean = true): ParsedLabelRow[] {
  const lines = text.split(/\r?\n/);
  const results: ParsedLabelRow[] = [];

  lines.forEach((line, idx) => {
    const trimmed = line.trim();
    if (skipEmptyLines && trimmed === '') return;

    // TSV形式 (変数名 \t ラベル) の判定
    if (line.includes('\t')) {
      const parts = line.split('\t');
      results.push({
        lineIndex: idx + 1,
        rawText: line,
        variableName: parts[0].trim(),
        label: parts.slice(1).join('\t').trim(),
      });
    } else {
      results.push({
        lineIndex: idx + 1,
        rawText: line,
        label: trimmed,
      });
    }
  });

  return results;
}
```

#### (2) 選択肢テキストパーサー (`parseQuickValueLabels`)
```typescript
export interface ParsedOption {
  code: string;
  label: string;
}

export function parseQuickValueLabels(text: string, startNumber: number = 1): ParsedOption[] {
  const lines = text.split(/\r?\n/).map(l => l.trim()).filter(Boolean);
  const options: ParsedOption[] = [];

  // 判定用正規表現 (例: "1: ラベル", "1 = ラベル", "1. ラベル", "1\tラベル")
  const numberedPattern = /^([0-9A-Za-z_-]+)[\s:=.\t]+(.*)$/;

  let autoNum = startNumber;

  for (const line of lines) {
    const match = line.match(numberedPattern);
    if (match) {
      options.push({
        code: match[1].trim(),
        label: match[2].trim(),
      });
    } else {
      // コードなしの場合は自動採番
      options.push({
        code: String(autoNum++),
        label: line,
      });
    }
  }

  return options;
}
```
