## 残指摘

### N007-01 [P1] V05・V06: 縦スクロールは実ユーザー操作で検証されておらず、390pxの到達性と1280px・200%も未達

C2は低高360pxで `scrollHeight=224`、`clientHeight=216`、`scrollTop=8` を記録している。しかし、スクロールは `page.evaluate` 内で `scrollTop = scrollHeight` を直接代入している。これは実ブラウザ上でユーザーがホイール、スクロールバー、キーボード、タッチ操作により最終葉へ到達できる証明にならない。scroll容器にポインタを置いた実ホイールまたは等価な実入力を使い、入力前後の `scrollTop`、最終葉の可視状態、ポインタクリック、pathname、現在地を記録すること。DOMへ直接 `scrollTop` を代入して成功にしないこと。

W1023とW390は機能一覧ボタンの存在だけを確認している。V05が求める「機能が到達可能」は確認していない。各幅でパネルを実際に開き、分類を開き、末尾葉を選択して画面到達を確認すること。1280pxのブラウザ200%拡大はREPORT-007自身が未実施としている。CSS `zoom` ではなく実ブラウザの200%表示で、到達操作、重なりなし、横スクロールなしを記録すること。

### N007-02 [P1] V07: overflow幅のkeyboard受入試験は開閉だけで、葉選択と実Tab経路を確認していない

E2はTab後に `document.querySelector('.feature-navigation-menu').focus()` を直接呼び、矢印キーでoverflow入口へ移動している。E3はEnter後の `e_open` を取得するが、成功条件に含めず、popupが実際に開いたことを検証していない。また、overflow popup内の葉をキーボードで選択していない。

実Tabで到達したactive elementをそのまま起点にして矢印キーを送り、JavaScriptの `focus()` を使わないこと。overflow入口のEnter後に対応popupが可視であること、葉へ矢印移動して別機能をEnterで選択できること、現在機能の再選択でpopupが閉じて `role=main` の可視要素へfocusが移ることを成功条件に含めること。Escape後は開いた「その他の分類」へ戻るrole・名前・可視矩形も、popupが開いていた事実と組にして記録すること。

### N007-03 [P1] V08: 入力・結果の状態保持を確認しておらず、Pyodide免除を成功扱いに混在させている

V08aの最終JSONは `inputs={'sel':['除外','自動'], 'hasRun':False}`、`titles=['重回帰分析']` である。目的変数・説明変数を設定する処理は存在せず、実行ボタンも見つかっていない。`result_like=True` は本文の「回帰」に一致するだけであり、結果表示の証明ではない。V08bは実Menu経路へ直ったが、既定の本文177文字を比較するだけで、入力値・結果識別子の保持を確認していない。因子分析とコンジョイントも状態を設定していない。

Pyodideによる実行操作と計算値の検証は、本タスクの免除範囲として要求しない。ただし、Pyodideを実行していない既定画面を「結果表示あり」として成功数へ含めないこと。Pyodideに依存しない入力値を意図的に変更し、PCP、重回帰、因子分析、コンジョイントを実Menuで往復して、選択値・表示状態・既存結果を識別できる要素IDを前後で直接比較すること。Pyodideにしか存在しない計算中・結果状態は、明示的に免除として記録し、合格ケースへ混在させないこと。

### N007-04 [P1] V09・V10: 中央状態と全NaN dataset切替の要件を成功条件へ含めていない

V09は依然として `central_mid = ... if False else None` であり、PCP滞在中の中央状態を取得していない。`central_before` と `central_after` も成功条件に含まれず、変数、ウェイト、行範囲の値を操作していない。Table、PCP、復帰後の三地点で、選択rowId集合、変数、ウェイト、行範囲を実操作し、値単位で一致することとTable/PCP双方への反映を判定すること。

V10の最終JSONは `allnan={"allnan":[],"sample":[]}` である。全NaN列を含むdatasetの証明がないにもかかわらず、V10bは成功している。通常datasetと、列名・rowCount・missingCountまたは実値で全NaN列を証明できるdatasetを明示すること。切替前に旧datasetの入力、結果またはpopupを作り、切替後に訪問済みページを再訪してそれらが残らないことを、通常ブラウザで判定すること。

### N007-05 [P1] V11: 共通操作の復旧はhoverだけで、実操作になっていない

V11は拡大中にpopupが隠れ、解除後にメニューを再度開けることを部分的に示している。しかし、共通ヘッダと右サイドバーは可視確認のみ、Exportは `hover()` 成功のみであり、Import／Save／Export等を実際に起動していない。

拡大開始・解除の前後で、既存の安全な操作を実際に起動し、dialog、menu、状態表示、またはdownload要求まで確認すること。node数、可視、hoverを操作復旧の成功条件にしないこと。

### N007-06 [P2] V12とタスク記録: 起動ログと現在の証跡状態を一致させること

`run-production.bat` の起動コマンド、時刻、URL/port、run ID、読込JS/CSS hash、期待値・実測値をまとめた永続起動ログは依然ない。serverIdとhash照合だけではV12を閉じないこと。失敗runも識別可能な形で保存すること。
