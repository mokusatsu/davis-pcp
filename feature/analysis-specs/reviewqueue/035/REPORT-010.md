# 通常表示レイアウト・可変ラベル横断修正報告

## 目的

グラフ拡大共通化後の通常表示を横断確認し、固定幅のHTML図、重複表題、可変長SVGラベル、縮小したCanvasの座標対応で残っていた表示不具合を整理した。

## 設計判断

1. 通常表示の幅は、HTMLのCard中心の図だけを親列幅へ追従させる。座標変換を持つSVG/Canvasへ一律の縮小transformは追加しない。
2. 表題はGraphPanelが担当し、内側Cardは説明・操作・描画内容だけを持つ。
3. 可変長の点名・ベクトル名・ノード名は、表示文字列を短縮し、SVGの`title`または既存tooltipで完全名を残す。端部ではtext-anchorを反転して描画境界の内側へ寄せる。
4. 焦点ペアCanvasはCSS表示矩形から論理座標へ変換する既存の`clientToCanvas`を維持する。親幅追従後も選択座標は変えない。

## 修正内容

| 区分 | 対象 | 修正 |
|---|---|---|
| 通常幅 | 頑健性分析 | 結論選択欄を折返し可能なflex配置へ変更し、トルネード図を親列幅へ追従させた。 |
| 通常幅 | 対話型棒グラフ、Penalty/Reward、KDA、ロジスティック回帰 | 固定幅の内側Cardを親列幅へ追従させ、狭い幅で横スクロールだけが残る状態を防いだ。 |
| 通常幅 | 焦点ペア図 | Canvasの表示幅を親列に追従させた。論理座標変換と集合選択は維持した。 |
| 重複表題 | 頑健性分析、対話型棒グラフ、Penalty/Reward、KDA、ロジスティック回帰 | GraphPanelと内側Cardに重複していた同一表題を内側から除去した。 |
| SVGラベル | TGT相関円、MCA、CA、FAMD | 端側のラベルを内向きに配置し、短縮表示と完全名の`title`を追加した。 |
| SVGラベル | 記述統計、分布、決定木、FAMD関係図、意外性散布図 | 可変長の列名・グループ名・ノード名・ペア名を利用可能な描画幅に合わせて短縮し、完全名を保持した。 |
| 折返し | 対話型棒グラフ | 層別行のラベル、集計ボタン、詳細を折返し可能なflex要素へ変更した。 |

## 横断確認の結果

可変SVGラベルのための全図共通の自動衝突回避機構は既存コードにない。既存の`truncateText`、CSS ellipsis、各描画子の座標計算を確認し、表示幅とデータ上限が異なる図へ一律の絶対配置を導入しない方針とした。

今回、可変長のデータラベルを持つ未保護の描画子を確認し、上表の対象へ短縮・境界内配置・完全名参照を追加した。軸目盛りや固定文言は各図の既存余白計算・折返しのままとし、選択操作や拡大表示の座標系は変更していない。
