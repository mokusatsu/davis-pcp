# 機能仕様書: Penalty-Reward 分析（三因子理論 / Penalty-Reward Contrast Analysis）

## 1. 概要・目的

各属性（品質・価格・サポートなどの評価質問）とアウトカム（総合満足度）の間に**非対称な関係**があるかを、ダミー変数回帰で推定し、属性を**三因子理論**（Kano モデル）に基づいて分類する機能。

- **当たり前品質（Basic / Must-be / 不満足要因）**: 不足すると不満が大きく増すが、充足しても満足はあまり上がらない。
- **一元的品質（Performance / One-dimensional）**: 不足で不満、充足で満足。線形の関係。
- **魅力的品質（Excitement / Delighter / 魅了要因）**: 不足しても不満にならないが、充足すると満足が大きく上がる。

これにより **「どこを直せば満足度が最も効率的に上がるか」** という行動指針を提示する。

## 2. 位置づけ・依存関係

- 入力はメタデータ付きデータモデル（01 と共通）。評価質問は順序（リッカート）であることを想定。
- 「Key Driver Analysis（04）」の重要度と組み合わせて、**重要度 × 非対称性の優先順位マップ**を構成できる。
- 出力の分類は「感度分析（03）」の `pra_class` 結論として登録可能。

## 3. 入力

- アウトカム変数: 総合満足度（順序または連続）。
- 属性バッテリー: 同一スケールの評価質問群（例: 5段階リッカート）。分析対象として複数選択。
- スケール情報: 最小値・最大値・中立点（neutral）をメタデータまたは手動指定から取得。

## 4. アルゴリズム

### 4.1 ダミー変数の作成

各属性 i について、評価を **Low / Neutral / High** の3区分に変換し、Neutral を参照カテゴリとして2つのダミーを作成する。

```
# 5段階（1-5）の場合、中立点=3
Low_i  = 1 if score_i ∈ {1, 2}        （下位ボックス / Bottom boxes）
High_i = 1 if score_i ∈ {4, 5}        （上位ボックス / Top boxes）
参照（Neutral）: score_i = 3
```

スケールの汎用ルール:

- 奇数段階（5点, 7点）: 中立点 = 中央値（3, 4）。Low = 中立未満、High = 中立超。
- 偶数段階（4点, 6点）: 中立点なし。Low = 下位半分、High = 上位半分（例: 4点なら Low={1,2}, High={3,4}）。この場合参照カテゴリは存在せず、Low ダミーのみを「High との対比」で解釈する（設定で明示）。
- Bottom/Top ボックスの定義（例: Top-2 Box を High とするか）は設定変更可能。

### 4.2 回帰モデル

全属性の Low/High ダミーを説明変数として、総合満足度を線形回帰する。

```
OverallSat = β0 + Σ_i ( β_low,i × Low_i + β_high,i × High_i ) + ε
```

- 属性ごとに**ペナルティ係数 = β_low**（期待: 負）と**リワード係数 = β_high**（期待: 正）が得られる。
- 係数の比較可能性のため、説明変数（ダミー）とアウトカムを標準化してから回帰する（標準化係数を使用）。
- 標本重みがあれば `WLS` で適用。

### 4.3 有意性の評価

- 各係数 `β_low`, `β_high` の p 値・95% CI を算出。
- さらに、**リワードとペナルティの非対称性**を検定する: `H0: |β_high| = |β_low|`。
  - 実装: `β_high + β_low`（符号を考慮した和）または `|β_high| - |β_low|` の線形結合の Wald 検定（`statsmodels` の `wald_test` / `t_test`）。

### 4.4 三因子分類ルール（有意性を考慮）

| 条件 | 分類 |
|---|---|
| `β_high` が有意に正、かつ `β_low` が非有意または |β_high| が |β_low| を有意に上回る | **魅力的品質（Excitement / Delighter）** |
| `β_low` が有意に負、かつ `β_high` が非有意または |β_low| が |β_high| を有意に上回る | **当たり前品質（Basic / Must-be）** |
| `β_low` が有意に負、かつ `β_high` が有意に正（非対称性なし） | **一元的品質（Performance）** |
| 両係数とも非有意 | **無関心要因（Indifferent / Low-impact）** |

数値的な分類補助（有意性が境界の場合）は、`asymmetry = |β_high| - |β_low|` の符号で判定し、`asymmetry` が閾値（既定: 標準誤差の1.96倍）を超えた場合のみ Delighter/Basic とし、それ以外は Performance とする。

### 4.5 結果の可視化

- **リワード vs ペナルティ散布図（象限図）**: x=Reward（β_high）, y=-Penalty（|β_low|）。4象限で分類を色分け。
  - 右上 = Performance、左上 = Basic（ペナルティ大・リワード小）、右下 = Excitement（リワード大・ペナルティ小）、左下 = Indifferent。
- **インパクト非対称チャート**: 属性ごとに、Low にしたときの満足度低下（penalty）と High にしたときの上昇（reward）を左右対称の棒で表示。
- **優先順位マップ（KDA連携時）**: x=重要度（04 の importance_pct）、y=asymmetry。改善優先度を「重要度が高く Basic/Performance」から順に提示。

### 5.2 自然言語ナラティブの生成

分類ごとにテンプレートで推奨文を生成する。

```
Basic:       「{label}」は当たり前品質です。不足時の不満が大きいため、まず最低水準の確保を優先してください。
Excitement:  「{label}」は魅力的品質です。充足させると満足度を大きく押し上げるため、差別化の機会です。
Performance: 「{label}」は一元的品質です。改善がそのまま満足度向上に直結します。
Indifferent: 「{label}」は現状、満足度への影響が小さい要因です。
```

### 6.3 インタラクション & DAVIS連携ワークフロー
1. **不満回答者群のPCP即時プロファイリング (`Select Dissatisfied Customers in PCP`)**:
   - 当たり前品質（例: サポート品質）で 1〜2 点をつけた 640 名を、ワンクリックで中央選択エンジンへ反映。
   - PCP画面に遷移すると、その 640 名の回答者の全軸（年代、契約年数、解約リスクスコア、利用頻度）が赤色ハイライトされる。
   - 分析者は「どの顧客セグメントが特にサポート不満に陥っているのか」を視覚的に特定可能。
2. **KDA（04）との双方向インポート連動**:
   - Feature 04 で算出した Shapley 重要度が、Kano マトリクス上の円の面積（バブルサイズ）に自動反映される。
   - 「当たり前品質かつ重要度が極めて高い（大バブル）」要素が最重要修正対象として直感的に浮き彫りになる。
3. **PCP軸自動アサイン (`Project Kano Axes to PCP`)**:
   - アウトカム、最優先Basic属性、最優先Performance属性、最優先Excitement属性の順にPCPの軸を自動再配置。
   - 属性の充足状況と総合満足度の束の挙動を直接検証可能。

## 7. パラメータ（設定可能）

| パラメータ | 既定 | 説明 |
|---|---|---|
| `low_boxes` | 中立未満 | 下位ボックス定義（カスタム指定可） |
| `high_boxes` | 中立超 | 上位ボックス定義（Top-2 Box 等に変更可） |
| `neutral_as_ref` | true | 中立を参照カテゴリとするか |

| `sig_level` | 0.05 | 有意水準 |

| `min_cell_n` | 30 | 各ダミーの最小度数 |

## 8. エッジケースと対処

| ケース | 対処 |
|---|---|
| 偶数段階スケール（中立なし） | Low/High 2分割に切替（参照なし）。設定で明示 |
| Low/High のセルが極小（<30） | 該当属性の係数に `small_base` 警告。信頼性低下を表示 |
| 全員が同じ評価（分散0）の属性 | 分析から除外し警告 |
| スケールの向きが逆（高=悪い） | メタデータで向きを確認し、必要なら反転を促す。自動反転はしない |
| アウトカムと属性が同一質問 | 除外（自己相関） |
| ダミー間の多重共線性（Low+High+Neutral がほぼ排他） | 参照カテゴリ方式で自然に回避。VIF を監視し異常時警告 |

## 9. パフォーマンス要件

- 回帰1本 + Wald 検定のみで軽量。10万行 × 30属性でも数秒以内。
- ブートストラップで係数の CI を出す場合（任意）のみ並列化。

## 10. 依存ライブラリ（Python 想定）

- `statsmodels`（OLS / WLS、`wald_test` / `t_test` による線形結合検定、標準化係数）
- `pandas` / `polars`, `numpy`

## 11. テスト計画

**単体テスト:**

1. ダミー生成: 5段階データで Low/High/Neutral が正しく振り分けられるか。
2. 偶数段階（4点）で Low/High 2分割に正しく切り替わるか。
3. 分類ルール: 各係数パターン（有意/非有意の組み合わせ）で正しい分類になるか。
4. 非対称性の Wald 検定が正しく計算されるか（既知データ）。
5. 標準化係数が `statsmodels` の結果と一致するか。

**統合テスト（合成データ）:**

6. 人工的に「Basic 属性」（Low で満足度が大きく下がり、High でも上がらない）を埋め込み、正しく basic と分類されるか。
7. 同様に Excitement / Performance を埋め込み、全分類が正しく再現されるか。

**受入基準:**

- 埋め込んだ3因子（Basic/Performance/Excitement）の分類再現率 > 0.9。
- 係数・p値が `statsmodels` の手動回帰と一致。
- 30属性でタイムアウトなし。
